Zone Table for Zen Cart tested on 2.1.0 & PHP 8.3
Version: 2.01
Date: 08/24/2024
PRO-Webs.net

If you have multiple shipping zones and you are not using this module, you cannot set table rate for more than one zone because the current built in table rate module is limited to only one zone.

I have modified the built in table rate module so that I can set separate table rate for 10 zones. Enjoy!

Support forum thread: http://www.zen-cart.com/forum/showthread.php?t=73166

Instructions:

Upload the includes directory to your Zen Cart installation, then access the plugin via your Zen Cart admin (modules >> shipping).
Click on zonetable 
Click install
Configure & save
Test
