# Multiple Zones Table Rate for Zen Cart

Version 2.1.0

Multiple Zones Table Rate adds one shipping module with separate table-rate settings for up to 10 Zen Cart zone definitions. Each zone can use its own rate table and handling fee, while the calculation can be based on order weight, price, or item count.

## Compatibility

- Zen Cart 2.0.1 through 2.2.2
- PHP 8.0 through 8.5

The module is encapsulated and does not modify Zen Cart core files.

## Features

- Up to 10 independently configured shipping zones
- Rates based on weight, order price, or item count
- Separate rate table and handling fee for each zone
- Percentage rates when price mode is selected
- Zone names displayed with the shipping quote
- Compatible with current Zen Cart language-file conventions
